# Dissertation Lifelog App

🚧 **Under development**

This app is a research prototype for my MSc dissertation, **Wearable Visual Memory Support for Dementia**.

It explores how wearable image capture, mobile review, and AI-assisted image selection could help create a smaller, more useful set of daily lifelog images for memory review.

## Current Focus

- Transfer images to the mobile app
- Review images from the day
- Filter or select relevant images
- Support AI-assisted image selection
